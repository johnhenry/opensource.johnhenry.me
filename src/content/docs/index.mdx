## The libraries

Every library is on npm, and some (the math family and parts of laya-js) are on JSR too. Most run in a browser
straight from a CDN with no bundler: [Using @johnhenry packages in the browser](/browser/) lists which ones and
how to load them with an import map or esm.sh.

## About

These are personal open-source projects, maintained under
[github.com/johnhenry](https://github.com/johnhenry) and published to npm under
the `@johnhenry/*` scope. The family was consolidated into the scope during
2026 — each package's docs carry a provenance note naming its prior unscoped
name, and versions restarted at 0.0.0 on import as a new-era marker, not a
maturity signal.

Commercial products live separately at [erisera.com](https://erisera.com).
